Política de Privacidade

Última atualização: 8 de outubro de 2026

Esta política explica como o Sylar acessa, usa, armazena e protege os dados das contas Google conectadas a ele.

1. Dados acessados

Com a autorização expressa do usuário na tela de consentimento do Google, o Sylar pode acessar:

  • Gmail: mensagens, metadados, rótulos e rascunhos, para ler, organizar, criar rascunhos e enviar e-mails. O Sylar não solicita permissão de exclusão permanente de mensagens.
  • Google Drive: arquivos e seus metadados, para localizar, ler, criar e editar arquivos.
  • Google Agenda: eventos, para consultar, criar e editar compromissos.
  • Perfil básico: endereço de e-mail, para identificar qual conta está conectada.

2. Como os dados são usados

Os dados são usados somente para executar tarefas pedidas pelo próprio usuário, como resumir e-mails, preparar respostas, organizar arquivos ou agendar compromissos.

Ações com efeito externo exigem confirmação do usuário antes de serem executadas. Isso inclui enviar e-mails, apagar ou compartilhar arquivos e convidar pessoas para eventos. Instruções encontradas dentro de e-mails ou documentos são tratadas como conteúdo, nunca como ordens.

3. Processamento por inteligência artificial

Para executar um pedido, trechos do conteúdo necessário podem ser enviados a provedores de modelos de IA, como OpenAI e Anthropic. Esse envio é feito apenas para gerar a resposta solicitada, pelas interfaces de programação (APIs) desses provedores.

Os dados de usuário obtidos das APIs do Google não são usados para treinar ou aperfeiçoar modelos de IA genéricos.

4. Armazenamento e segurança

  • Os tokens de autorização e os dados necessários ficam em um servidor privado controlado pelo responsável pelo Sylar, com acesso restrito.
  • Credenciais e tokens não são publicados nem compartilhados.
  • Os dados são mantidos apenas pelo tempo necessário para a tarefa ou enquanto a conta permanecer conectada.

5. Compartilhamento

Os dados não são vendidos, alugados nem usados para publicidade. O Sylar não os compartilha com terceiros, exceto:

  • com os provedores de IA descritos na seção 3, para executar o pedido;
  • quando exigido por lei.

6. Uso Limitado (Google API Services User Data Policy)

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado (Limited Use).

7. Revogação e exclusão

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. Após a revogação, os tokens deixam de funcionar.
